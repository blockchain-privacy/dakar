# Dakar

Dash analytics and transaction tracking. Research and development.

# Repository structure

* [backend](backend) - The backend, which is composed of a crawler which exposes a REST API.
* [app](app) - The frontend for the backend, which is written in Vue.js.
* [docker](docker) - Docker configuration and docker-compose files.
* [data](data) - Data and non-code project files.
