# Dakar

CoinJoin analytics and transaction tracking. Research and development.

# Repository structure

* [backend](backend) - The backend crawls available blockchain data, exposes a restful API and provides CoinJoin tracking services.
* [app](app) - The frontend built with Vue and Vuetify.
* [docker](docker) - Docker configuration and docker-compose files.
* [data](data) - Data and non-code project files.
